Common issues

  • Stats took a while to show? Companion API indexing takes 10–30s after a match starts.
  • Overlay won't respond to clicks? Click-through is on. Press Ctrl+Shift+C.
  • Wrong Steam account? Restart the overlay after switching accounts.
